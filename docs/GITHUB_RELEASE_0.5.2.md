## CTRL_DEF v0.5.2

### Changes

Rig Score no longer penalizes checks that do not apply. Fixed three false positives: DEF_ prefix matching is now case-insensitive, deform status is checked against actual weights, and switch bones referenced by drivers count as active.

The score box shows one category per line, with labels no longer cut off. Naming Doctor now works with the active mesh and includes a rename map field in the sidebar. The guide at the bottom now has 7 steps.
