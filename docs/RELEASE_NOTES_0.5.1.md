Two fixes for the sidebar panel.

Rig Score: the score box now stays visible after you run it, even with the character mesh selected instead of the armature. Before, the score only appeared if the armature itself was the active object.

Naming Doctor: clicking it with nothing to rename used to stop with an error. Now it simply says there is nothing to rename. It also checks every name before changing anything, so a bad entry cannot leave the rig half renamed, and the armature ends in the same mode it started.
